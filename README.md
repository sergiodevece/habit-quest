# Habit Quest

Aplicación gamificada de hábitos con sistema de recompensas y confetti, pensada para convertir pequeñas rutinas diarias en una experiencia más motivadora.

## Objetivo del proyecto

El objetivo de esta app es ayudar al usuario a mantener hábitos positivos mediante una interfaz sencilla, visual y divertida.

La propuesta utiliza elementos de juego, como recompensas y celebración visual, para reforzar la constancia sin convertir la organización personal en una hoja de cálculo con complejo de notario.

## Características principales

- Seguimiento de hábitos diarios.
- Sistema de recompensas.
- Celebraciones visuales con confetti.
- Enfoque gamificado para mejorar la motivación.
- Proyecto ligero orientado a navegador.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Estado del proyecto

Proyecto funcional en fase inicial de aprendizaje y mejora continua.

## Aprendizajes trabajados

Con este proyecto se practican conceptos como:

- Diseño de apps de hábitos.
- Aplicación de gamificación en herramientas personales.
- Gestión de interacción con JavaScript.
- Creación de feedback visual para el usuario.
- Organización de una aplicación web pequeña y funcional.
